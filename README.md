# reclaimco-social

Public image and video host for Reclaim Co. social posts. Buffer needs a public
link to each file, so finished graphics are pushed here and scheduled from
`https://raw.githubusercontent.com/jessicajuanita-gif/reclaimco-social/main/<path>`.

- `posts/` single-image posts (1080x1350)
- `carousels/<name>/slide-NN.png` carousel slides, in order
- `stories/` Instagram stories (1080x1920)
- `reels/` Reels (MP4)
- `photos/` photos of Jessica

The source files and captions live in the private `reclaimcowebsite` repo,
under `instagram/`. Don't host social images on reclaimco.com.au.
